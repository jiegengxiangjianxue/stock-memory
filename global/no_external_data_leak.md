---
name: no_external_data_leak
description: Standing safety rule when using any external tool or API during research.
---
Never transmit local private data, credentials, tokens, or project-internal file contents to external tools, APIs, or search engines. When researching public references (bettbox, FlClash, sing-box-lx), query only public URLs or search terms; do not paste local config dumps, .env contents, or build logs into external requests.
