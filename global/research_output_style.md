---
name: research_output_style
description: When the user asks for comparative/research output, follow these evidence rules.
---
- Every recommendation must cite a real URL or local file:line; no unverified claims.
- If a source cannot be verified, explicitly state so and rely on the project's verified spec (PROGRESS.md).
- Output is read-only: no file writes, no credentials, no mutations.
- Cap: ≤6 recommendations per request.
- Style: concrete, evidence-backed, no speculation.
