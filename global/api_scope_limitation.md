description: 解释当前股票接口权限范围，澄清误解
---
当前提供的股票数据接口为公开市场基础行情接口，仅包含实时价格、涨跌幅、成交量等核心字段。

**关于外部数据源的说明：**
- 不支持直接连接 GitHub/GitCode/SkillsHub 等第三方平台数据库
- 不允许进行网页实时抓取（涉及合规与版权问题）
- 内置插件系统目前未开放股票数据扩展能力

如需更多数据维度（如财务指标、分析师评级、新闻舆情等），可通过以下方式实现：
1. 联系数据供应商获取付费接口授权
2. 使用官方支持的第三方数据服务（如Wind、同花顺iFinD等）
3. 本地部署数据同步服务并导入到允许的数据源

当前版本聚焦于稳定、合规的基础行情服务。
