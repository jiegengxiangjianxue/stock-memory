name: user_preference_股票分析框架
description: 用户要求股票分析系统必须包含周期池、板块池、低位股票池三个维度，而非仅热点和AI推荐
---
用户明确要求优化算法，至少需要1GB以上的算法规模。核心批评点：当前系统仅有"热点池"和"AI推荐"两个功能，且AI推荐全是涨停股。

用户期望的完整框架应包含：
1. **周期池**：利用数据库 + 实时热点 + 周期算法 + 每日复盘
2. **板块池**：利用数据库 + 实时热点 + 板块轮动 + 每日复盘
3. **低位股票池**：尚未涨停的低位票、今天买入明天能涨的低位票

这是用户对股票分析工具的功能性需求，跨项目通用。
