---
name: multi_server_and_github_sync
description: 项目采用多服务器架构，算法/自动化在独立服务器运行，GitHub 作为数据、算法、接口的中央同步仓库
---
- 网站与算法/自动化更新分置于两台服务器；自动化更新若未在独立服务器成功执行，网站侧数据会保持旧值（曾出现数据停在某一时点未刷新）。
- 用户要求将已有数据、算法、接口、框架统一同步到 GitHub，GitHub 视为代码与数据的单一可信源。
- 操作顺序：先在独立服务器确认自动化任务已跑完并产出新数据 → 拉取/同步到网站服务器 → 最后 git push 到 GitHub 保持三端一致。
