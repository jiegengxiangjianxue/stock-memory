所有 GitHub 仓库（仓库名、简介、README、代码注释及可见文档）必须仅使用英文，不允许出现中文。用户明确要求仓库名称和介绍用英文以减少被人搜到：不要把仓库名、描述或介绍改回中文，也不要在公开元数据里加便于检索的中文标题或关键词。提交或发布前需检查仓库描述与项目文档语言。
