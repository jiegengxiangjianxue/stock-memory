# factor_lab 实测结论 (2026-10-16)

`scripts/factor_lab.py` 在全市场全历史上用统一口径 (次日开盘买入→第N日收盘卖出,
单边滑点0.03%, 涨跌停限制, 封跌停顺延) 测量 12 个候选特征 x 4 持有期 (1/3/5/10日)。
1200 只股票, 55.7 万随机基准样本。防自欺设计: 不调参寻优/输出全部特征含无效的/
同口径 random_baseline/min_edge 默认 0.10pp (差距小于此值视为噪声)。

## 唯一有效的买入信号
**below_ma60** (收盘 < MA60*0.95, 深度跌破60日线):
- 1日 +0.07% (t=3.48, edge +0.12pp)
- 3日 +0.34% (t=23.61, edge +0.20pp)
- 5日 +0.60% (t=32.49, edge +0.30pp)
- 10日 +1.06% (t=42.8, edge +0.42pp)
→ edge 随持有期**递增**, 是均值回归而非噪声。持有越久边际越大 → 应拉长持有期到5-10日, 不是T+1。

## 强负面信号 (全部统计显著, t=-3~-8)
- breakout_60 (60日新高): 1日 -2.19% / 3日 -2.50% / 5日 -2.70% ← 最负面
- new_high_20 (20日新高): 1日 -1.43% / 3日 -1.56% / 5日 -1.98%
- rsi_overbought (RSI>70): 1日 -0.46% / 3日 -0.49% / 5日 -0.40%
- gap_up (跳空高开>2%): 1日 -0.55% / 3日 -0.45% / 5日 -0.45%
- vol_ratio_high (放量2倍): 1日 -0.48% / 3日 -0.45% / 5日 -0.48%
→ **所有「追突破」类都是负期望**, 与 engine_v5 的「突破加分」方向相反, 是明确改进点。

## 有收益但打不赢随机 (不当有效信号)
rsi_oversold / bias_ma20(乖离<-5%) / vol_dry_up(缩量上涨) — 3日和5日转正但 edge < 0.10pp。
ma_golden (MA5>MA20金叉) 完全无预测力。

## 交叉验证
与上一轮 weight_calibrator_v3 的发现**完全一致**: 看空胜率 54.4% > 看多 43.8%。
两个独立方法 (分层统计 / 全市场特征测量) 得到同一结论 → 当前市场环境下「回避」比
「追涨」有效。这不是巧合。

## 局限 (未解决)
- 未计佣金/印花税 (实盘每笔约0.1%+, 对1日持有期致命)
- 未分 regime 分层 (混合市况稀释信号)
- 资金类特征未纳入 (缺历史 moneyflow, 当前只存实时)
- 本地 bulk K 线只到 10-13, 全量需在 CI 上跑

## 怎么用
`python3 scripts/factor_lab.py --hold-days 1,3,5,10 --max-stocks 1200`
产出 data/factor_lab.json + data/factor_lab.md。
改 engine_v5 / multidim 权重前先跑这个, 别拍脑袋。
