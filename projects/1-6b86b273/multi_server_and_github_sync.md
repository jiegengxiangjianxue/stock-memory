名称：multi_server_and_github_sync
摘要：项目采用多服务器架构，算法/自动化在独立服务器运行，GitHub 作为数据、算法、接口和框架的中央同步仓库。

关键规则：
1. 架构分离：网站与算法/自动化更新分置于两台服务器；自动化更新若未在独立服务器成功执行，网站侧数据会保持旧值。
2. 单一可信源：用户要求将已有数据、算法、接口、框架统一同步到 GitHub，GitHub 视为代码与数据的单一可信源。
3. 同步流程：先在独立服务器确认自动化任务已跑完并产出新数据 → 拉取/同步到网站服务器 → 最后 git push 到 GitHub 保持三端一致，并验证内容完整性。
