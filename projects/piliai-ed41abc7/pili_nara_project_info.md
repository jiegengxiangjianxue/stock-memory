PiliNara 是位于 ~/workspace/piliai 的 Android 项目。应用包名为 `com.example.piliai`，debug 构建的应用 ID 后缀为 `.debug`。当前版本为 `versionName "1.0.0"`、`versionCode 1`。GitHub 仓库为 `qwerzxcva/piliai`。技术栈：Kotlin + Jetpack Compose + Rust native (ARM64)，网络层用 Ktor + Wbi 签名，存储用 Room + DataStore，播放用 Media3 ExoPlayer。
